# TinyFish

TinyFish is present in the existing integration catalog and can be configured for engine-managed runners. Its remote agent tools can perform actions, so they are not automatically treated as read-only company-research tools.

## Local profile status

The first local research profile does not expose TinyFish autonomous task execution. A service being registered in the shared catalog does not mean every operation is allowed in this mode.

Use [public page reading](web.md), [Playwright](playwright.md) and an explicitly selected [search provider](../integrations.md) for the documented company workflow.

## Existing runner path

The [runner integration guide](https://github.com/dalkedev/plompy-engine/blob/main/docs/integrations.md) describes TinyFish configuration and authentication. Native runner OAuth and API-key bridge settings remain separate from this gateway.

## Costs and uncertainty

Remote agent runs may consume credits and can have effects on websites. Do not automatically repeat an uncertain run. Check the vendor's result before deciding to retry. Never use a real form submission or message as a connectivity test.

Adding a future local adapter requires an actual policy boundary and appropriate acceptance tests; a read-only label in documentation would not provide that boundary.
